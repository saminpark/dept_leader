# Fran:D 제조네트워크 v2

프랜차이즈 브랜드·가맹본부·제조사·제품·원재료를 조회하는 정적 웹페이지입니다.

## 데이터 원칙

- 최초 기준: `FranD_ver2_프랜차이즈_제조제품_최종DB.xlsx`.
- 기존 v1 HTML의 제품 기록은 합치지 않습니다.
- `제조제품_최종DB`와 `프랜차이즈_마스터`를 별도로 읽습니다. 제품이 연결되지 않은 브랜드도 마스터에서 조회합니다.
- 가맹점 0~1개 또는 점당매출 0원인 브랜드는 조회 대상에서 제외합니다. 필수 값이 없는 경우에는 검증 오류로 처리합니다.
- 제품 신고기록의 명칭 연결을 조회하는 도구이며 납품계약의 유무를 판정하지 않습니다.
- 같은 본사라는 이유로 여러 브랜드에 제품을 자동 귀속하지 않습니다.
- 브랜드·본사·제품명 등은 원문을 보존합니다. 검색용 정규화와 별칭은 표시명을 바꾸거나 제품 연결을 추가하지 않습니다.

## 반복 업데이트

`source/latest.xlsx` 위치에 수정한 최종 DB를 교체해 커밋합니다. 파일명을 고정하면 다음 업데이트 때에도 같은 위치만 교체하면 됩니다.

필수 시트:

| 시트 | 역할 |
|---|---|
| 제조제품_최종DB | 브랜드와 제조 제품 연결 기록 |
| 프랜차이즈_마스터 | 제품 연결 유무와 관계없는 전체 유효 브랜드 |
| 매칭_검토후보 | 별도 검토 목록. 연결된 제품 수에 합산하지 않음 |
| 기준과_집계 | 원본의 집계 기준과 메모 |

GitHub Pages 배포 과정에서 엑셀을 읽고 검증한 뒤 데이터 파일을 생성합니다. 검증에 실패하면 새 버전을 배포하지 않고 이전 배포본을 유지합니다. 최종 갱신일과 실제 파일 기준 집계는 페이지에서 확인합니다.

화면에서 엑셀을 불러오는 기능은 미리보기용입니다. 공유 데이터의 영구 변경은 위 원본 파일을 GitHub에 커밋해야 합니다. GitHub 토큰이나 API 키를 페이지에 입력하지 않습니다.

이 폴더는 기존 신사업실 데스크 및 R&R 페이지와 별도로 관리합니다.
